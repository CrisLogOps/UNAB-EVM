# Frontend web — OpenEVM (Next.js)

Ambiente **local**. No publica ni empuja al remoto.

```bash
cd apps/web
npm install
npm run dev
```

Abre http://localhost:3000 → redirige a `/demo`.

Identidad visual alineada a [openevm.netlify.app](https://openevm.netlify.app/). El pie de página conserva el contexto de trabajo (rama Dev, Seminario de Grado UNAB).
