# Matriz RBAC (borrador)

Permisos atómicos del dominio MVP:

| Código | Descripción |
|--------|-------------|
| `baseline.upload` | Carga de Línea Base (CSV/Excel) |
| `baseline.freeze` | Congelamiento de versión (v1.0) |
| `baseline.replan` | Replanificación (v2.0+) |
| `progress.submit` | Subida de avance |
| `cost.ac_upload` | Carga de costos reales ($AC$) |
| `evidence.upload` | Subida de evidencia |
| `evidence.approve` | Aprobación de evidencia → desbloqueo de $EV$ |
| `evm.read` | Lectura de KPIs y Curva S |
| `rbac.admin` | Administración de áreas/roles (Owner/CEO) |

Detalle completo y matriz por rol: ver sección 2 del [README](../README.md).
